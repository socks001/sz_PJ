## 1. 定位与设计原则

### 1.1 首页要完成的事

访客不需要阅读任何长文，只要顺着页面往下滑，就能依次判断四件事：

1. **经历是否真实**：工作、实习、项目与教育能否与简历对上（S1.5）。
2. **技术范围**：这个人用过哪些技术、覆盖到哪一层（视图、构建、部署、观测）。
3. **工程成熟度**：是否有取舍意识、性能意识、兼容与无障碍意识、交付流程意识。
4. **实现深度**：页面上的动效与交互是否由本人实现，难度如何，能否解释清楚。

首页本身就是证据：不需要"我精通 X"，只需要让访客在这一页上看到 X 被用对。

### 1.2 五条可判定的设计原则

| 编号 | 原则 | 可判定的解释 |
| --- | --- | --- |
| P1 | 一屏一个焦点 | 任意一屏内同时只有 1 个视觉主焦点；不允许两个元素争夺第一眼 |
| P2 | 留白即结构 | 区块间距 ≥ 96px（移动端）；同区块内相邻信息组间距 ≥ 24px；不用装饰性分割线堆积层级 |
| P3 | 动效只做解释 | 每个动效必须回答"从哪来 / 到哪去 / 两者什么关系"；除首屏滚动提示外无循环装饰动画 |
| P4 | 证据优先 | 每一条能力声明都必须有可核对或可现场验证的路径：一个可点的重播、一个可测的数值、一条可查的版本号 |
| P5 | 层级靠明度 | 全站不使用彩色强调色；层级只靠 3 级文本明度 + 字号 + 留白 + 等宽字体区分 |

### 1.3 技术信息的写作规范

- **只写已实现**：不写"计划中 / 即将支持 / 正在重构"。
- **数值必须带口径**：任何性能数字都要能回答"在哪台设备、什么网络、用什么工具、什么时候测的"。
- **禁止不可验证的形容词**：不出现"精通 / 熟练掌握 / 深入理解 / 高性能 / 极致体验"。
- **禁止编造**：未实测的性能与兼容数据只写目标值与验收阈值，并注明"构建后实测并留档"；身份类信息一律用 `【示例：…】` 占位并登记 §11.1，不得伪造真实姓名、联系方式或履历。
- **取舍必须写代价**：任何"选择了 A"都要同时说明"放弃了什么、付出了什么"，否则视为无效信息。
- **一处只讲一件事**：一个条目只承载一个结论，不把三条信息塞进一段话。

### 1.4 明确不做的事

- 不展示第三方项目案例、不做"精选作品"、不做客户 Logo 墙。
- 不做技能雷达图、技能百分比进度条、星级评分。
- 不做自我介绍长文（超过 140 字必须折叠，且首页推荐不写）。
- 不做轮播 Banner、自动播放视频、订阅弹窗、首屏加载进度条。
- 不做滚动劫持（不覆写系统滚动速度）、不做全屏 scroll-snap 分页。
- 不展示无法复现的跑分或截图；所有证据必须与当前线上版本一致。

## 2. 全局规格基线

### 2.1 视口与安全区

- 设计基准：375 × 812；适配 360–430 宽度不出现横向滚动。
- 首屏使用动态视口高度语义，地址栏收起/展开时首屏内容始终占满可视区且不被裁切。
- 固定导航与底部元素避让刘海与 Home 指示条，安全区外不放可点击元素。
- 允许用户双指缩放（可访问性要求），不锁定缩放。

### 2.2 色彩

### 2.3 字体与文案层级

字体：系统默认无衬线字体（SF Pro / 苹方 / Roboto / 思源黑体），不加载第三方 Web 字体。
等宽字体：系统等宽（SF Mono / Roboto Mono / ui-monospace），用于版本号、路径、命令、指标键名，不额外下载字库。

| 层级 | 用途 | 移动端 字号/行高 | 桌面端 字号/行高 | 字重 | 字距 | 颜色 |
| --- | --- | --- | --- | --- | --- | --- |
| Display | 首屏主标题 | 40 / 44 | 64 / 68 | 600 | -0.02em | 主文本 |
| H2 | 区块标题 | 28 / 34 | 44 / 50 | 600 | -0.01em | 主文本 |
| H3 | 条目名称 | 20 / 26 | 22 / 30 | 600 | 0 | 主文本 |
| Body | 说明、要点 | 15 / 24 | 16 / 26 | 400 | 0 | 主文本或次文本 |
| Caption | 元信息、标签、备注 | 13 / 20 | 13 / 20 | 400 | 0 | 次文本 / 三级文本 |
| Eyebrow | 区块英文小标 | 11 / 14，全大写 | 12 / 16，全大写 | 500 | 0.12em | 三级文本 |
| Number | 指标数值 | 32 / 36，等宽数字 | 36 / 40，等宽数字 | 600 | -0.01em | 主文本 |
| Mono | 版本、路径、键名 | 13 / 20 | 13 / 20 | 400 | 0 | 次文本 |

文案硬性规则：

- 标题不加句号；正文不使用感叹号；不出现"赋能 / 闭环 / 抓手"类词。
- 中文与英文、数字之间留半角空格；英文小标统一大写。
- 单个文本块最多 3 级层级（标题 / 说明 / 元信息），不出现第 4 级。
- 同一区块内所有"说明"文本长度差不超过 30%，避免排版失衡。

### 2.4 间距与栅格

- 基准 4px；实际只用 8 的倍数：8 / 16 / 24 / 32 / 48 / 64 / 96 / 128 / 160。
- 页边距：移动端 20px，平板 32px，桌面 40px。
- 容器最大宽度 1120px，桌面水平居中；正文单行最大 34 个汉字（约 44 字符）。
- 区块纵向间距：移动端 96px，平板 120px，桌面 160px。
- 区块标题到首个内容：移动端 32px，桌面 40px。
- 条目间距：移动端 24px，桌面 32px；组间距 48px。
- 段落 12px；同一信息组内部 8px。

### 2.5 圆角、描边、阴影

- 卡片 / 演示区圆角：移动端 16px，桌面 20px；封面类大图圆角 20 / 24px。
- 按钮为全圆角胶囊（高 48px，左右内边距 24px）。
- 分隔线 1px，高分屏渲染为 0.5px 视觉厚度。
- 不使用投影；浮层只用背景模糊 + 遮罩色。

### 2.6 动效令牌

| 令牌 | 时长 | 缓动 | 使用场景 |
| --- | --- | --- | --- |
| D-feedback | 120ms | 标准缓出 | 按压、开关、图标微调 |
| D-fast | 220ms | 标准缓出 | 颜色、描边、下划线、hover 位移 |
| D-base | 320–400ms | 标准缓出 / 两端缓 | 小元素入场、手风琴、折叠 |
| D-slow | 640ms | 标准缓出 | 条目、区块标题、演示区入场 |
| D-narrative | 800–1200ms | 标准缓出 | 首屏序列、数字递增、连线绘制 |

- 标准缓出：起速快、收尾极缓（等价 0.22, 1, 0.36, 1）。
- 两端缓：等价 0.65, 0, 0.35, 1。
- 滚动联动使用线性，不做缓动。
- 入场位移：小元素 16px，条目 24px，区块标题 32px，一律自下而上。
- 交错延迟：条目 70ms，列表行 90ms，菜单项 60ms，演示点 120ms。
- 入场触发：元素顶边进入视口底部 15% 时触发；元素高度超过视口 60% 时改为 25%。
- 入场只播一次，不反向播放；同一会话内不重复。

### 2.7 技术信息的排版规则

- **数值与单位**：数值用 Number 层级，单位用 12px 次文本，与数值间距 2px，不换行；如 128 KB、1.8 s。
- **版本号 / 路径 / 键名**：使用 Mono 层级，保留原文大小写；版本号前不加 "v"，除非项目本身如此书写。页面只展示 package.json 声明区间的主版本（如 `5.x`），补丁号以 `pnpm-lock.yaml` 解析结果为准，不在页面上展示。
- **状态**：文字（已支持 / 部分支持 / 未测试 / 待测）+ 状态点；不使用图标单独表意。
- **禁止模糊修饰**：不给实测值加"约 / 左右 / 接近"；若为区间，写明区间与条件。
- **可复制**：技术名称、版本号、邮箱允许选中复制，不对正文使用禁止选择的样式。
- **占位标记**：未决信息写 `【待填：…】`，示例占位写 `【示例：…】`；两类都必须全角方括号开头，便于全局检索与替换；示例占位不得出现在上线版本。
- **一屏一表**：同一区块内最多出现 1 个表格（移动端转为卡片列表），避免多表堆叠。

### 2.8 素材规格

| 类型 | 规格 | 体积上限 | 说明 |
| --- | --- | --- | --- |
| 背景光晕 | 纯渐变实现，或 1 张 WebP | ≤ 60KB | 仅首屏 1 处 |
| 简历 PDF | A4，≤ 2 页 | ≤ 1.5MB | 由作者提供【待填】 |
| 图标 | 24 × 24，1.5px 描边 | 内联矢量 | 单色 #F5F6F7 |
| 分享图（OG） | 1200 × 630 | ≤ 200KB | 暗底 + 主标题，无第三方 Logo |
| 页面截图 | 不使用 | — | 技术信息一律文字化，避免截图过期失真 |

首页不使用视频、GIF、序列帧、第三方统计脚本的可视组件。

### 3.2 顺序理由

**是什么（S1）→ 做过什么（S1.5）→ 用了什么（S2）→ 怎么组织（S3）→ 做得多细（S4）→ 有多快（S5）→ 边界在哪（S6）→ 怎么交付（S7）→ 怎么联系（S8）**。

经历紧跟首屏，因为访客的第二判断是"这个人是否真实、做过什么"，一条可扫读的时间线比技术清单更快建立可信度；技术栈随后展开，回答"技术面是否匹配"；动效演示放在中段，因为它是唯一需要访客动手的部分，需要前面先建立信任；性能与兼容放在演示之后，此时访客已有"想验证"的动机。

### 3.3 移动端整页节奏

| 位置 | 留白 / 节拍意图 |
| --- | --- |
| S1 | 满屏；底部留 96px 空白承接滚动提示，建立"每一屏之间是空的"印象 |
| S1 → S1.5 | 首屏随滚动淡出，S1.5 标题延后 100ms 入场，形成一次呼吸 |
| S1.5 | 7 行时间线纵向排列，行间用 1px 细线分隔；每行 86–114px，首屏之外快速扫完 |

| S2 | 4 组纵向排列，组间 48px；靠组名与细线分隔，不用卡片包围 |
| S2 → S3 | 96px 空白；S3 起首是一句架构结论，节奏由"清单"转为"论述" |
| S3 | 分层说明短，取舍卡长，形成"先快后慢"的阅读速度变化 |
| S3 → S4 | 96px 空白；S4 出现第一块可交互演示区，是页面唯一"亮"起来的位置 |
| S4 → S5 | 96px 空白；S5 用大号数字收束，节奏由"读"转为"看" |
| S5 → S6 → S7 | 两个紧凑区块，间距保持 96px，信息密度提高但留白不变 |
| S7 → S8 | 96px 空白；S8 标题放大到接近首屏，收尾 |

## 4. 区块逐条规格

**内容项**

- 页面不足一屏无法滚动：隐藏"回到顶部"。

## 5. 全局交互与动效

### 5.1 固定导航

- 高度 56px + 顶部安全区；初始透明无背景。
- 滚动超过 80px：背景变为 72% 底色 + 背景模糊（240ms）。
- 向下滚动累计 120px：导航上移隐藏（240ms）；向上滚动累计 40px：恢复（240ms）。阈值不对称，防抖动。
- 移动端：左侧显示姓名缩写或英文名（≤ 8 字符，示例 `【示例：LIN】`），右侧为两条 20px 横线组成的菜单图标。
- 菜单展开：全屏遮罩自下而上 360ms；菜单项为 6 个锚点（经历 / 技术栈 / 架构 / 动效 / 性能 / 联系），28px 大字逐项入场（交错 60ms）；关闭 320ms。
- 桌面端：左侧 logo，右侧横排 6 个锚点 + 邮箱文字链接；无菜单图标。
- 当前所在区块的锚点在导航中提亮（主文本），其余为次文本；切换无动画或 ≤ 200ms 渐变。
- 锚点点击后菜单自动关闭，目标区块标题距视口顶部留 72px（避开固定导航）。

### 5.2 滚动行为

- 全站禁用横向滚动；任何元素不得横向溢出。
- 锚点平滑滚动：时长按距离 400–700ms，两端缓。
- 不劫持滚轮 / 触摸滚动速度，不做惯性自绘滚动。
- 不使用 scroll-snap 强制分页。
- 滚动联动只作用于 transform 与 opacity，不触发重排。
- 离屏的循环动画与演示区自动暂停。

### 5.3 手势

- 只使用"轻触 / 点击"；不实现左右滑动切换、长按菜单、拖拽排序。
- 不做自定义双击缩放；保留浏览器原生缩放。
- 所有可点击元素热区 ≥ 44 × 44px，间距 ≥ 8px。

### 5.4 页面转场（本版不生效）

- 本版为单页，无详情页与独立演示页，S4 只在原地重播，本节规格暂不适用。
- 若后续新增独立演示页，按以下执行：演示区内容放大为全屏（420ms），返回时反向（360ms）并恢复滚动位置。

### 5.5 减弱动效（系统开启"减弱动态效果"时）

- 关闭位移、视差、缩放、循环浮动；首屏序列压缩为一次性 300ms 淡入，总时长 ≤ 400ms。
- 演示区自动播放关闭，仅保留手动重播；重播时只播放透明度变化。
- 数字直接显示终值；指标线直接显示终值。
- 流水线连线直接显示完整线条，节点一次性点亮。
- 平滑滚动改为瞬时跳转；导航显隐保留。
- 折叠展开保留，时长压缩到 160ms。

### 5.6 性能守则

- 动画属性白名单：transform、opacity、filter（仅导航模糊）。
- 禁止动画 width / height / top / left（折叠高度除外，需测量后过渡）。
- 视口外内容延迟渲染；演示区进入视口前 300px 才开始初始化。
- React 岛与演示区脚本按 `client:visible` 加载，首屏 HTML 不依赖水合即可阅读。
- 所有图片声明宽高比，避免布局偏移。
- 首屏不加载视频、第三方字体、地图或非必要脚本。

### 5.7 文本与复制

- 不对正文使用禁止选择的样式；技术名称、版本、邮箱允许选中复制。
- 复制失败必须有可见反馈，不得静默失败。
- toast 同时只存在 1 条，新提示替换旧提示，不堆叠。
